# Quantum Gates
Quantum gates are mathematical operations that change the state of qubits.
- X Gate: The Pauli-X gate acts as a quantum NOT gate, flipping |0> to |1> and vice versa.
- Y Gate: The Pauli-Y gate rotates the state around the Y-axis of the Bloch sphere.
- Z Gate: The Pauli-Z gate flips the phase of the |1> state, leaving |0> unchanged.
- H Gate (Hadamard): Creates an equal superposition. Applying H to |0> creates (|0> + |1>)/sqrt(2).
- CNOT Gate: The Controlled-NOT gate flips the target qubit if and only if the control qubit is |1>. It is essential for creating entanglement.

# Entanglement
Entanglement is a quantum phenomenon where two or more qubits become perfectly correlated.
Measuring one entangled qubit instantaneously determines the state of the other, regardless of distance.
The standard way to create entanglement is by applying a Hadamard (H) gate to one qubit, followed by a CNOT gate connecting that qubit to a second qubit. This creates a Bell state.
